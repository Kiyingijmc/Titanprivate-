## Adversarial traces

- **Restart:** latch is a DB column, so a reboot cannot re-open the window; covered by
  `test_correction_survives_a_restart` (real close/reopen of the SQLite file).
- **Re-register (`register_order`) resets the latch** via INSERT-OR-REPLACE column default.
  Traced every re-register path: OPENED (once per ticket; a duplicate OPENED rewrites the entry
  from meta, so re-opening the window is the *correct* behavior and self-heals next heartbeat —
  POSITION_PRICE_OPEN is stable for a position's life, so re-correction lands on the same true
  fill, never a ratchet-era price) and heartbeat adoption (guarded by `exists(tid)`, fires only
  for unknown tickets). No corruption path found; the docstring documents the reset.
- **MARKET scoping vs how order_type is recorded:** `order_type` comes from `meta['cmd']` which
  is `decision['type']` — `'MARKET'`/`'LIMIT'`/`'STOP'` (incl. the LIMIT→MARKET conversion at
  system_controller.py:610-612, exactly the slippage-prone case). The meta-less OPENED fallback
  registers the EA's echoed request `cmd` (Titan_Gateway.mq5:158 echoes the command, no price
  field), so those rows register entry=0 and get filled by the correction branch first heartbeat.
- **LIMIT/STOP:** keep resting price and still flip PENDING→ACTIVE — tested for both types.
- **Adopted manual positions:** registered `"Adopted"/"MARKET"` with `entry = p`; the later
  correction rewrites the same POSITION_PRICE_OPEN value. Harmless, management unaffected.
- **Live-DB migration:** existing open MARKET rows have `entry_synced=0` after ALTER TABLE, so
  the next heartbeat one-time-corrects them to the true broker fill — the intended remediation
  for in-flight trades, not a corruption (the heartbeat `p` is the open price, never an SL).
- **Zero/missing `p`:** never clobbers, latch stays open for the real price — tested.
- **Out of scope:** no `mql5_bridge/`, `risk_manager.py`, `trade_manager.py`, or backtest files
  touched (diff is exactly 3 files). `initial_tp` semantics unchanged and tested.
