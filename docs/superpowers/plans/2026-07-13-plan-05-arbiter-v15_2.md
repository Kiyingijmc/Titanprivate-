**Complete code for `src/arbiter/intent.py`:**

```python
"""Intent: a strategy's request to trade, submitted to the Arbiter.

Frozen and JSON-scalar so intents journal cleanly. Strategies never
execute; they emit Intents. The Arbiter decides.
"""
from dataclasses import dataclass, field, asdict

# Higher = better. Unknown grades rank 0 (worst).
GRADE_RANK = {"A++": 6, "A+": 5, "A": 4, "B+": 3, "B": 2, "C": 1}


def grade_rank(grade: str) -> int:
    return GRADE_RANK.get(grade, 0)


@dataclass(frozen=True)
class Intent:
    strategy_id: str          # manifest id (attribution key — NOT instance name)
    symbol: str
    direction: str            # "BUY" | "SELL"
    kind: str                 # "MARKET" | "LIMIT" | "STOP" (mirrors decision['type'])
    price: float
    sl: float
    tp: float
    grade: str = ""
    confidence: float = 0.0   # strategy-native [0,1]; 0.0 = not provided
    thesis_id: str = ""       # idempotency key; "" = auto (symbol:direction:price:sl)
    priority: int = 50        # manifest priority (lower wins ties)

    def effective_thesis(self) -> str:
        return self.thesis_id or f"{self.symbol}:{self.direction}:{self.price!r}:{self.sl!r}"

    def to_payload(self) -> dict:
        return asdict(self)
```

**events.py additions** (exact pattern of existing events):
`IntentEmitted(strategy_id, symbol, direction, kind, grade, thesis)` and
`IntentBlocked(strategy_id, symbol, direction, rule, detail)` — all str fields, "" defaults.

**Tests (5):** frozen/immutability; `effective_thesis` auto vs explicit; `grade_rank` ordering (A++ > A+ > ... > C > unknown); both events round-trip via `Event.from_dict`; `to_payload` JSON-serializable (`json.dumps` succeeds).

### Task 2: Arbiter pipeline

**Files:** Create `src/arbiter/arbiter.py`; test `tests/unit/test_arbiter.py`.

**Contract (Produces):**

```python
class Arbiter:
    def __init__(self, config=None, publish=None):
        # config keys (defaults): opposition_policy="higher_grade_wins" | "block_both",
        # max_positions_per_symbol=1, max_total_positions=6, thesis_ttl_bars=12
        # publish: callable(Event) | None (no-op if None)
    def submit(self, intent: Intent) -> None      # publishes IntentEmitted; collects for this cycle
    def resolve(self, open_positions, bar_key="") -> list[Intent]
        # open_positions: list of dicts with at least 's' (symbol) and 'type' or direction info
        #   (the controller passes self.current_open_positions — HEARTBEAT shape:
        #    {'t': ticket, 's': symbol, 'p': price, 'vol': lots, ...}; direction may be
        #    absent — treat any open position on the symbol as blocking per
        #    max_positions_per_symbol; opposite-direction detection uses the state_manager
        #    row when available — see controller task; for the Arbiter, accept an optional
        #    per-position 'dir' key and treat missing as "unknown" which counts toward the
        #    symbol cap but NOT the opposition rule).
        # Pipeline order (deterministic): 1) thesis dedup (seen within thesis_ttl_bars,
        # keyed by effective_thesis + bar-count aging via bar_key changes);
        # 2) same-symbol same-direction dedup: keep best (grade_rank desc, priority asc,
        #    strategy_id asc); 3) opposition rule per policy; 4) symbol cap vs
        # open_positions + already-approved this cycle; 5) total cap.
        # Every drop publishes IntentBlocked(rule=...) with detail. Clears the cycle buffer.
    def stats(self) -> dict  # counters per rule: submitted, approved, blocked_by[rule]
```

Determinism: resolution order = sorted submissions (grade_rank desc, priority asc, strategy_id asc, symbol asc); rules applied in the numbered order; no randomness, no clock (thesis aging counts `resolve` calls with distinct `bar_key`, capped memory: drop thesis entries older than `thesis_ttl_bars` distinct keys; bound the seen-set size structurally).

**Tests (~10, author them):** single intent passes untouched (the SilverBullet case — assert the returned object IS the submitted intent); thesis replay within TTL blocked, after TTL allowed; same-symbol-same-direction keeps A+ over B and publishes IntentBlocked(rule="dedup") for the loser; opposition higher_grade_wins picks winner, equal grades → both blocked; opposition block_both policy blocks both; symbol cap blocks when an open position exists on that symbol; unknown-direction position counts for the cap but not opposition; total cap enforced across symbols (approved-this-cycle counts); stats counters accurate; publish=None safe.
