# Frozen completed-session range parent

One new research parent, evaluated on M15 with M5 execution. This is a reversal hypothesis around an externally defined time range, rather than the previous rolling 12-bar extreme with a sweep exactly two bars before the FVG. It is not claimed to increase signals or returns before testing.

- Reference range: the same New York calendar day's 00:00–09:30 bid OHLC range, frozen at 09:30. Require all 38 completed, contiguous M15 bars with opens 00:00 through 09:15. Do not substitute partial ranges. Retain seasonal broker-local clock conversion.
- Event: the first M15 bar opening at or after 09:30 and closing at or before 10:30 which strictly breaches and closes back inside one range boundary. Sweep below the low and close above it proposes BUY; above the high and close below it proposes SELL. A bar breaching both boundaries abandons the day, regardless of close. Only one event per day; later sweeps do not reset its age.
- Invalidation: after the event, any completed bar closing back beyond the swept reference boundary abandons the event. Later ambiguous bars breaching both range boundaries also abandon it. These rules act before FVG admission on that close.
- Entry parent: first directional three-bar FVG with middle-candle directional body at least its ATR14 (simple true-range average), whose middle bar occurs strictly after the event bar. Thus event index <= signal index-2, but need not equal it. Parent closes must be before 11:00 and no more than 60 minutes after the event close. Use at least 50 prior M15 bars as in the control.
- Midpoint LIMIT; original structural stop from the most adverse price between event and parent, buffered by 0.1 parent ATR, with minimum distance one parent ATR. Require finite positive geometry and spread+commission <=0.25R. Cost rejection may allow a later FVG from the same event before expiry; it does not select a new event.
- One admitted parent per symbol/day, no market confirmation layer, no retest-after-confirmation layer. Fixed 2R target, 45-minute exclusive pending TTL, 180-minute holding limit, existing spread/commission assumptions and 1x/1.5x stress, OHLC/OLHC paths.

Use the existing nine symbols and early/late/extension partitions with uninterrupted M5 segments and full 225-minute parent lifecycle coverage. Keep old wider-window midpoint controls as frozen, hash-verified comparison rows; all existing history is reused development evidence. Do not call the extension an independent validation set. No broker calls or live changes.

Freeze and report day coverage, complete reference ranges, first events, invalidations, eligible parents, fills/expiries, sample size, per-symbol breadth and returns. Shortlist only if all paths/costs/periods are positive, improve mean R over the old wider-window control, have >=150 early/100 late/100 extension fills, and late/extension each have >=3 symbols with >=20 fills and a majority positive. Report frequency changes separately; do not trade off failures against a more attractive total signal count.

If shortlisted, any later independent validation must use observations not examined in these studies, ideally a separately recorded prospective period. Passing this development screen is not live authorization. No parameter grid, fallback range, post-result window adjustment or symbol exclusion is part of this experiment.
